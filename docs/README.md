# DesktopSplit 文档

- `designs/`：产品设计、交互设计、线框和视觉资产
- `decisions/`：架构决策和重要取舍记录
- `notes/`：调研、头脑风暴和临时分析
- `testing/`：测试计划、验收记录和兼容性报告
- `reference/`：Windows、WPF、Win32 等外部参考资料
