# Decision 0002：首版实现架构

状态：已接受

日期：2026-09-22

## 决策

首版使用 C# WPF 作为设置窗口和应用生命周期，使用 Win32 `user32.dll` 处理窗口枚举、工作区坐标、窗口位置和原生最大化状态；托盘使用 Windows Forms `NotifyIcon`。

窗口管理先用约 180ms 的轻量轮询识别用户的原生最大化动作。普通窗口不移动；识别到最大化后按窗口中心点选择区域，恢复窗口并填充对应工作区。该方案不安装虚拟显示器驱动，也不实现自动吸附。

## 原因

- 不需要驱动签名、虚拟显示器和复杂安装器，符合轻量工具定位；
- WPF 适合承载可视化布局设置，Win32 能直接得到 Windows 工作区和窗口状态；
- 轮询足以支撑首版交互，后续如需更低延迟或更强兼容性，可替换为 WinEvent hook，而不改变布局模型。

## 边界

首版只提供单显示器优先、矩形区域、托盘暂停/恢复和当前用户启动项；全屏、系统对话框、置顶工具窗口、UAC 安全桌面和虚拟显示器不属于首版验收范围。
