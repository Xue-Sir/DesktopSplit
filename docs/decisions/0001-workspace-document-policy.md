# Decision 0001：项目文档统一放在工作区

状态：已接受

日期：2026-09-21

## 决策

DesktopSplit 的项目文档、设计稿、线框、测试记录和参考资料统一保存在当前工作区的 `docs/` 目录下，并按用途分类。

## 分类

- `docs/designs/`：产品设计、交互设计、线框和视觉资产
- `docs/decisions/`：架构决策和重要取舍
- `docs/notes/`：调研、头脑风暴和临时分析
- `docs/testing/`：测试计划、验收记录和兼容性报告
- `docs/reference/`：外部技术文档和参考资料

## 原因

设计资料直接跟随项目目录，后续实现、测试和复盘时不依赖工具私有目录；分类目录也避免设计稿、临时笔记和测试证据混在一起。

## 影响

后续新增项目文档默认先写入上述目录。gstack 私有目录可以保留跨会话副本，但工作区 `docs/` 是项目的规范文档位置。
