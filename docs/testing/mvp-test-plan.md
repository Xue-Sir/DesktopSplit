# DesktopSplit 首版测试计划

## 环境

- Windows 10，单块物理显示器；
- 建议先用记事本、资源管理器、浏览器等普通窗口测试；
- 分别测试 100%、125% 或 150% 显示缩放；
- 首版不把 UAC、全屏视频、系统对话框作为成功标准。

## 手工验收

1. 启动程序后只出现托盘图标，不自动移动已有窗口。
2. 从托盘打开设置，预览显示 `4/5 + 1/5`，拖动分隔线后比例文字和预览同步变化。
3. 设置页显示当前工作区的像素宽高，并显示每个区域的实际像素尺寸；输入各区域宽度后，合计等于工作区宽度时可以应用。
4. 点击“应用”，让普通窗口分别位于左右区域；点击窗口最大化按钮或双击标题栏，窗口填充其中心所在区域。
5. 再次执行窗口还原，窗口回到最大化前的位置和大小。
6. 普通窗口拖到另一侧后再次最大化，应按新的中心位置进入另一侧区域；不应发生自动吸附。
7. 应用新布局时，已经由工具管理的窗口立即跟随新区域；未最大化的普通窗口保持原位。
8. 通过托盘“暂停分区”后，原生最大化应使用 Windows 默认行为；恢复后再测试自定义最大化。
9. 保存一个自定义预设，重启程序后预设仍存在。
10. 切换“开机后自动启动”，检查当前用户启动项是否同步变化。

## 需要记录的问题

- 应用名称、窗口标题、显示缩放比例；
- 操作前后窗口左上角和尺寸；
- 是否为最大化、全屏或置顶窗口；
- 是否能通过托盘退出且进程消失。
